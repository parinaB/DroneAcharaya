## Column meanings

- **Requirement (as stated)** — quote or tightly paraphrase the PS. Do not
  reword into what we happen to have built.
- **Our Deliverable** — the concrete artefact that satisfies it.
- **Where It Lives** — repo path, so a judge can be pointed at it directly.
- **Evidence / Demo** — the specific demo step, metric or figure that proves it.
- **Status** — `not started` / `in progress` / `done` / `descoped (reason)`.
